# 03 — Конкуренти для аналізу

Продукт: особистий CRM для дизайнера (див. `CLAUDE.md`). Він збирає задачі з Trello (основна робота), Telegram (друга робота) і особисті справи на одну спільну дошку. Плюс таймер, «Настрій дня», ачівки, XP і реальні нагороди.

Базова задача: **не губити жодної задачі, бачити, хто і звідки її поставив, і відчувати, що день пройшов не дарма.**

> «Відкрито без логіну» складено з моїх знань, у браузері не перевірялось. Позиції з позначкою _(перевірити)_ треба підтвердити перед розбором.

---

## 1. ХАРД — той самий продукт, та сама аудиторія

Персональний хаб, який зводить задачі з кількох робочих інструментів в одне місце, для фрилансера або спеціаліста з кількома джерелами задач.

**Про наш ринок:** прямого українського конкурента з інтеграцією Trello + Telegram для дизайнера не знайдено. Ринок фактично міжнародний, а Telegram як джерело задач — наша прогалина.

### Akiflow
- **Група:** хард
- **Чому тут:** «universal inbox», який збирає задачі з Trello, Slack, Gmail, Notion, Asana тощо в одне місце і планує їх у календар. Найближчий аналог нашої ідеї.
- **Що вивчити:** як inbox показує джерело задачі (іконки, кольори); швидкий захват задачі (хоткей, command bar); розбір inbox → план дня; двосторонню синхронізацію з Trello.
- **Відкрито без логіну:** лендинг, сторінка цін, help center, відео-демо на YouTube. Сам продукт — тільки після реєстрації (trial).

### Sunsama
- **Група:** хард
- **Чому тут:** щоденний планер, що тягне задачі з Trello, Asana, Gmail, Slack. Побудований навколо ритуалів «ранкове планування» і «завершення дня».
- **Що вивчити:** ранковий ритуал (аналог нашого «Настрою дня»); ритуал завершення дня (аналог «Підсумку дня»); оцінку часу на задачу та попередження «ти перевантажив день»; спокійний тон інтерфейсу.
- **Відкрито без логіну:** лендинг, ціни, документація (help center), блог, YouTube-огляди. Застосунок — після реєстрації (trial).

### Morgen
- **Група:** хард
- **Чому тут:** календар і планер, що агрегує задачі з Todoist, Notion, ClickUp, Linear тощо. Задачі «вкидаються» в календар.
- **Що вивчити:** як задачі з різних джерел співіснують в одному календарі (для нашого календаря задач); кольорове кодування джерел.
- **Відкрито без логіну:** лендинг, ціни, документація. Застосунок — після реєстрації.

### Bonsai
- **Група:** хард
- **Чому тут:** all-in-one для фрилансерів, зокрема дизайнерів: клієнти, проєкти, задачі, таймер, рахунки. Та сама аудиторія, наша третя черга (гроші, білінг).
- **Що вивчити:** модель «клієнт → проєкт → задача → час → рахунок»; таймер з білінгом; як фрилансер бачить, хто скільки винен.
- **Відкрито без логіну:** лендинг, ціни, публічні шаблони (договори, інвойси, пропозиції) _(перевірити)_. Продукт — після реєстрації (trial).

### Plutio
- **Група:** хард
- **Чому тут:** ще один all-in-one для фрилансерів (задачі, таймер, клієнти, інвойси) з сильною кастомізацією вигляду і брендингу.
- **Що вивчити:** кастомізацію кольорів і теми (аналог нашої «теми під настрій»); як різнорідні сутності вміщаються в одному інтерфейсі без перевантаження.
- **Відкрито без логіну:** лендинг, ціни, help center _(перевірити)_. Продукт — після реєстрації (trial).

## 2. СОФТ — інший продукт, та сама базова задача

Не агрегатори, але ними так само ведуть задачі, не губляться й мотивують себе.

### Trello (Atlassian)
- **Група:** софт
- **Чому тут:** наше основне джерело задач. Kanban, з яким користувач працює щодня. Наша дошка має бути не гіршою за нього.
- **Що вивчити:** анатомію картки (обкладинка, мітки, чекліст, вкладення); drag-and-drop між колонками; які поля Trello API віддає для синхронізації.
- **Відкрито без логіну:** лендинг, галерея шаблонів, публічні дошки (переглядаються без акаунта), документація REST API для розробників.

### Todoist (Doist)
- **Група:** софт
- **Чому тут:** еталонний to-do для особистих і робочих задач, проєкти, пріоритети. Плюс легка гейміфікація «Karma» (очки, рівні, стріки).
- **Що вивчити:** швидке додавання задачі природною мовою; пріоритети P1–P4; систему Karma як мінімальну гейміфікацію; поділ особистого і робочого.
- **Відкрито без логіну:** лендинг, галерея шаблонів, help center, блог. Застосунок — після реєстрації (є безкоштовний план).

### TickTick
- **Група:** софт
- **Чому тут:** задачі, календар, Pomodoro-таймер і трекер звичок в одному застосунку. Майже наш набір другої черги.
- **Що вивчити:** таймер-фокус, прив'язаний до задачі; як календар, задачі і звички вживаються разом; статистику фокус-часу.
- **Відкрито без логіну:** лендинг, help center, блог. Застосунок — після реєстрації (є безкоштовний план).

### Habitica
- **Група:** софт
- **Чому тут:** to-do лист, повністю перетворений на RPG: XP, рівні, золото, нагороди, які користувач задає сам. Пряма відповідь на нашу ідею реальних нагород за XP.
- **Що вивчити:** механіку «власні нагороди за зароблені очки»; баланс XP за задачі різного розміру; чого уникати (перевантаженість, «дитячість» для робочих задач).
- **Відкрито без логіну:** лендинг, публічна вікі з повним описом механік, open-source код на GitHub. Застосунок — після реєстрації.

### Toggl Track
- **Група:** софт
- **Чому тут:** трекер часу для фрилансерів (старт/стоп і ручне внесення, звіти для білінгу). Наша друга черга.
- **Що вивчити:** UX кнопки старт/стоп; ручне редагування записів часу; звіти «на себе» і «для клієнта»; як не забути вимкнути таймер.
- **Відкрито без логіну:** лендинг, ціни, документація, публічний API. Продукт — після реєстрації (є безкоштовний план).

## 3. АСПІРАЦІЙНІ — еталони рішення задачі

Не конкуренти, а планка якості: хто найзрозуміліше, найкрасивіше чи найемоційніше розв'язує частини нашої задачі.

### Linear
- **Група:** аспіраційний
- **Чому тут:** еталон швидкого, чистого task-інтерфейсу. Має **Triage** — inbox для вхідних задач перед тим, як вони потраплять у роботу. Це прямий аналог наших «Можливих задач» з Telegram.
- **Що вивчити:** Triage (прийняти, відхилити, відкласти); статуси й переходи; command bar і хоткеї; мікроанімації; щільність інформації без хаосу.
- **Відкрито без логіну:** лендинг, документація, changelog з відео кожної фічі, есе «Linear Method». Продукт — після реєстрації (безкоштовний план).

### Things 3 (Cultured Code)
- **Група:** аспіраційний
- **Чому тут:** найкрасивіший і найспокійніший менеджер особистих задач. Поділ «Сьогодні / Заплановане / Колись», Apple Design Award.
- **Що вивчити:** екран «Сьогодні» (відповідь на «з чого почати день»); анімацію закриття задачі; типографіку і повітря; як особисте і робоче живуть поруч.
- **Відкрито без логіну:** лендинг з детальними описами й відео, support-статті. Застосунок для Mac має безкоштовний trial і не потребує акаунта.

### Duolingo
- **Група:** аспіраційний
- **Чому тут:** світовий еталон гейміфікації та емоційного дизайну: XP, стріки, ліги, ачівки, святкові анімації, персонаж.
- **Що вивчити:** анімації нагород і моментів «ти молодець»; механіку стріків і їх «заморозки»; екран завершення сесії (аналог «Підсумку дня»); грайливий тон мікротекстів.
- **Відкрито без логіну:** лендинг і блог; на вебі можна почати урок без акаунта _(перевірити)_. Повний досвід — з профілем.

### Finch
- **Група:** аспіраційний
- **Чому тут:** self-care застосунок з улюбленцем, який починає день з питання про настрій і підлаштовує цілі під стан. Найближчий еталон нашого «Настрою дня».
- **Що вивчити:** check-in настрою (вибір, візуалізація, наслідки); м'які цілі в поганий день; емоційну мову без провини; систему нагород.
- **Відкрито без логіну:** лендинг; мобільний застосунок дозволяє почати без реєстрації _(перевірити)_.

### Superhuman
- **Група:** аспіраційний
- **Чому тут:** еталон швидкого розбору вхідного потоку («inbox zero»). Наша задача з Telegram — це саме потік повідомлень, з яких треба швидко вирізнити задачі.
- **Що вивчити:** розбір потоку клавіатурою; стани «прочитано / відкладено / готово»; святкування порожнього inbox; онбординг, що вчить швидкості.
- **Відкрито без логіну:** лендинг, блог з есе про продуктовий дизайн, відео-демо. Продукт — тільки з акаунтом Gmail/Outlook і платною підпискою (trial).
