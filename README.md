# CRM-MMMY

Особистий CRM для дизайнера. Задачі з **Trello** і **Telegram** плюс особисті справи в одному яскравому, анімованому інтерфейсі з **ачівками, XP і реальними нагородами**.

## Що вміє (план)
- **MVP**: єдиний список і Kanban задач (Tasks → In Progress → In Review → Approved), двостороння синхронізація з Trello, збір задач з Telegram-чату через бота, особисті задачі й нагадування, ачівки та XP, кастомізація кольорів під настрій.
- **Далі**: таймер часу, календар задач, нотатки, статистика й графіки, нагадування в Telegram.
- **Потім**: гроші й білінг, калькулятори, нові джерела задач, темна тема.

## Стек
Next.js · TypeScript · Tailwind · Motion · Supabase · Drizzle · grammY · Trello API

## Хостинг
Vercel Hobby + Supabase Free: **$0/міс**. Проєкт self-hostable: форкаєш, підключаєш свої Trello і Telegram, і в тебе власна CRM.
